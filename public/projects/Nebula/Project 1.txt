Nebula is a Unity-powered multiplayer action RPG built in C#. It uses Unity Netcode for networking, Unity Input System for controls, URP for rendering, and a suite of Unity tools such as Cinemachine, UI Toolkit/UGUI, and TextMeshPro. The game includes character creation, combat, progression, enemy AI, and save/load systems, with Steam-related support and a networked host/client setup.
